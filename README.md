# Pokédex DS

Aplicação acadêmica em React + Vite + TypeScript, em desenvolvimento.

## Executar

Na raiz do repositório:

```bash
npm install
npm run dev
```

Abra o endereço exibido pelo Vite no terminal.

## Verificar

```bash
npm run typecheck
npm run lint
npm run build
```

O build verifica os tipos antes de gerar a aplicação em `dist/`.

## Organização

- `src/`: código React em TypeScript (`.tsx`) e estilos.
- `src/css/`: estilos da aplicação.
- `public/`: arquivos estáticos servidos diretamente pelo Vite.
- `index.html`: entrada HTML.
- `vite.config.ts`: configuração do Vite.
- `tsconfig.json`: configuração do TypeScript.
- `README.vite.md`: documentação original do template.

O JSON obrigatório do professor ainda será adicionado. A interface atual é o template inicial, sem as funcionalidades da Pokédex.
